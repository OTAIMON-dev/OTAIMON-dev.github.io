# OTA IMON Studios - Official Website

A high-performance, single-page landing site designed for indie game developers. Built with clean HTML5, CSS3, and lightweight Vanilla JavaScript.

## Highlights
- **Zero Dependencies:** Pure vanilla stack, loads in milliseconds.
- **Bilingual / i18n Ready:** Native English & Portuguese toggle with browser detection and `localStorage` persistence.
- **Press & Fan Frictionless:** Direct Steam Wishlist links (with UTM tags) and quick press kit downloads.
- **Free GitHub Pages Hosting:** Fully compatible with custom domain configurations.

## Folder Structure
```text
├── index.html        # Main markup
├── style.css         # Dark cyberpunk / tactical sci-fi theme
├── script.js         # i18n localization logic
├── assets/           # Place your screenshots, logos, and art assets here
└── CNAME             # (Optional) Your custom domain, e.g. otaimon.com
```

## How to Deploy to GitHub Pages
1. Push all files to a public GitHub repository.
2. In your repo: **Settings > Pages > Source -> Deploy from branch: main / root**.
3. Add your custom domain in **Custom Domain**.
